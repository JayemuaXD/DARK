# DARK Core (darkcore)

Mod núcleo del modpack DARK para Minecraft Java 1.21.1 / Forge 52.1.0.

Visión resumida
- Modpack: DARK — terror de día, calma de noche.
- Mod núcleo: DARK Core
- mod_id: darkcore
- package base: com.jayemuaxd.dark.core

Contenido en este repositorio
- roadmap-modpack.md — roadmap completo del proyecto (guía viva del diseño y estado técnico).
- README.md (este archivo)
- .gitignore — recomendado para desarrollo en Windows/Gradle/IDE
- LICENSE — licencia MIT por defecto (puedo cambiarla si preferís otra)

Cómo contribuir
1. Cloná el repositorio:
   git clone https://github.com/JayemuaXD/DARK.git
2. Creá una rama para tu cambio:
   git checkout -b feat/mi-cambio
3. Hacé commits atómicos y abrí un Pull Request cuando estés listo.

Archivos opcionales
- Si querés que agregue un esqueleto de mod Forge (build.gradle, settings.gradle, src/...), decímelo y lo subo en una rama separada.
